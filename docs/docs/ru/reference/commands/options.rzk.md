# Опции

Команды `#set-option` и `#unset-option` управляют опциями тайпчекера.

## Синтаксис

```{.rzk}
#set-option "<option-name>" = "<value>"
#unset-option "<option-name>"
```

## Доступные опции

### `verbosity`

Управляет уровнем детализации прогресса в выводе при проверке типов.

- `"silent"` — без вывода логов
- `"normal"` — вывод прогресса проверки типов (по умолчанию)
- `"debug"` — вывод каждого промежуточного действия (полезно для отладки)

### `render`

Управляет бэкендом визуализации для диаграмм.

- `"svg"` — включить визуализацию в формате SVG
- `"latex"` — включить визуализацию в формате LaTeX
- `"none"` — отключить визуализацию (по умолчанию)

### `warn-overhang`

Управляет нефатальной подсказкой, которая печатается, когда грань ограничения или условие `recOR` выходит за пределы локального контекста топов (не следует из него, но пересекается с ним). Такой «выход за пределы» допустим — например, при ограничении уже определённой фигурой, грани которой заданы на всём кубе, — поэтому подсказка носит информационный характер. Проверка требует обращения к решателю для каждой грани, поэтому по умолчанию она выключена.

- `"yes"` — печатать подсказку для выходящих за пределы граней и условий
- `"no"` — не проверять выход за пределы (по умолчанию)

### `warn-tope-family-domain`

Управляет предупреждением о семействе топов, не содержащемся в своей объявленной области. Семейство `χ : ψ → TOPE` обозначает топ внутри `ψ`, и тайпчекер читает его как пересечение с областью: конкретное семейство `\ t → φ`, проверяемое против `{t : I | ψ} → TOPE`, элаборируется в `\ t → ψ ∧ φ`, если только из `φ` уже не следует `ψ`. Когда конъюнкт добавляется, проверенное семейство отличается от записанного, о чём и сообщает предупреждение. Например, внутренний рог, объявленный над `Δ³` с гранями, записанными на всём кубе, читается как рог внутри `Δ³`, что обычно и имеется в виду. Проверка не требует ничего сверх вывода, который решает, нужен ли конъюнкт.

- `"yes"` — предупреждать о семействе, не содержащемся в своей объявленной области (по умолчанию); код предупреждения — `TopeFamilyDomainWarning`
- `"no"` — не предупреждать (семейство всё равно читается как пересечение с областью)

## Примеры

```rzk
#lang rzk-1

-- Установить подробность в тихий режим
#set-option "verbosity" = "silent"

-- Включить визуализацию SVG
#set-option "render" = "svg"

-- Позже отключить визуализацию
#unset-option "render"

-- Вернуть подробность в нормальный режим
#set-option "verbosity" = "normal"
```

## Примечания

- Опции устанавливаются на оставшуюся часть файла (или до сброса)
- `#unset-option` возвращает опцию к её значению по умолчанию
- Неизвестные имена опций или недопустимые значения приведут к ошибке проверки типов
