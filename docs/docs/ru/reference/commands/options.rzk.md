# Опции

Команды `#set-option` и `#unset-option` управляют опциями тайпчекера.

## Синтаксис

```{.rzk}
#set-option "<option-name>" = "<value>"
#unset-option "<option-name>"
```

## Доступные опции

### `verbosity`

Управляет уровнем детализации прогресса в выводе при проверке типов.

- `"silent"` — без вывода логов
- `"normal"` — вывод прогресса проверки типов (по умолчанию)
- `"debug"` — вывод каждого промежуточного действия (полезно для отладки)

### `render`

Управляет бэкендом визуализации для диаграмм.

- `"svg"` — включить визуализацию в формате SVG
- `"latex"` — включить визуализацию в формате LaTeX
- `"none"` — отключить визуализацию (по умолчанию)

### `warn-overhang`

Управляет нефатальной подсказкой, которая печатается, когда грань ограничения или условие `recOR` выходит за пределы локального контекста топов (не следует из него, но пересекается с ним). Такой «выход за пределы» допустим — например, при ограничении уже определённой фигурой, грани которой заданы на всём кубе, — поэтому подсказка носит информационный характер. Проверка требует обращения к решателю для каждой грани, поэтому по умолчанию она выключена.

- `"yes"` — печатать подсказку для выходящих за пределы граней и условий
- `"no"` — не проверять выход за пределы (по умолчанию)

### `warn-tope-family-domain`

Управляет предупреждением о семействе топов, не содержащемся в своей объявленной области. Семейство `χ : ψ → TOPE` обозначает топ внутри `ψ`, и тайпчекер читает его как пересечение с областью: конкретное семейство `\ t → φ`, проверяемое против `{t : I | ψ} → TOPE`, элаборируется в `\ t → ψ ∧ φ`, если только из `φ` уже не следует `ψ`. Когда конъюнкт добавляется, проверенное семейство отличается от записанного, о чём и сообщает предупреждение. Например, внутренний рог, объявленный над `Δ³` с гранями, записанными на всём кубе, читается как рог внутри `Δ³`, что обычно и имеется в виду. Проверка не требует ничего сверх вывода, который решает, нужен ли конъюнкт.

- `"yes"` — предупреждать о семействе, не содержащемся в своей объявленной области (по умолчанию); код предупреждения — `TopeFamilyDomainWarning`
- `"no"` — не предупреждать (семейство всё равно читается как пересечение с областью)

### `warn-free-standing-restriction`

Управляет предупреждением о свободно стоящем ограничении в позиции предположения. Ограничение называется _ext-style_, когда оно стоит на кодомене Π по фигуре; именно такие ограничения даёт кодирование типов расширения RSTT. Консервативность над RSTT доказана для выводов, в которых свободно стоящее ограничение выводится, но никогда не предполагается (раздел 5 статьи о Rzk[^1]), поэтому тайпчекер сообщает о позициях предположения: тип связанной переменной, мотив элиминатора, тип типа тождества и тип, переданный как данные (в том числе тело определения со значением в `U` и аргумент на параметре, тип которого — вселенная). Тип, переданный как данные, важен потому, что позже он подставляется в позиции связывания и мотивов. Выводимые типы не проверяются, включая ограничение под обычным `Π`.

- `"yes"` — предупреждать о предполагаемом свободно стоящем ограничении (по умолчанию); код предупреждения — `FreeStandingRestrictionWarning`
- `"no"` — не предупреждать

Проверка синтаксическая: ограничение, возникающее в позиции предположения лишь после раскрытия определения или редукции, не обнаруживается.

### `warn-meta-binder`

Управляет предупреждением о схематической переменной, связанной внутри терма. Префикс параметров определения — это его метатеоретический контекст параметров, благодаря чему определение читается как семейство утверждений объектной теории, по одному на каждую инстанциацию (см. `warn-meta-prefix`). λ _внутри_ терма, связывающая переменную типа вселенной, `CUBE`, `TOPE` или функции в один из них, выходит за рамки этого чтения. Ведущие λ в теле определения — это его собственные параметры, о них предупреждения нет.

Две позиции всё ещё считаются префиксом параметров. Ветви разбора случаев, до которого префикс ещё не кончился: схема, определённая рекурсией по схематическому индексу, обязана сначала разобрать индекс и только затем связать остальные параметры, причём и индекс, и эти параметры попадают в метапрефикс, так что всякое использование их передаёт. И аргумент на схематическом параметре — та самая «сантехника», которую уже разрешает `warn-meta-prefix`.

- `"yes"` — предупреждать о схематическом связывании внутри терма; код предупреждения — `MetaBinderWarning`
- `"no"` — не предупреждать (по умолчанию)

По умолчанию проверка выключена: разработка может упаковать утверждение с квантором по вселенной в тип и доказать его λ-термом, что принято на практике, хотя и выходит за рамки соответствия со слоем параметров.

## Примеры

```rzk
#lang rzk-1

-- Установить подробность в тихий режим
#set-option "verbosity" = "silent"

-- Включить визуализацию SVG
#set-option "render" = "svg"

-- Позже отключить визуализацию
#unset-option "render"

-- Вернуть подробность в нормальный режим
#set-option "verbosity" = "normal"
```

## Примечания

- Опции устанавливаются на оставшуюся часть файла (или до сброса)
- `#unset-option` возвращает опцию к её значению по умолчанию
- Неизвестные имена опций или недопустимые значения приведут к ошибке проверки типов
