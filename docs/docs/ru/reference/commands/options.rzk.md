# Опции

## Предупреждение об области определения семейства топов

По умолчанию проверяющий алгоритм предупреждает, если конкретное семейство топов не содержится в объявленной области определения. Семейство интерпретируется как его пересечение с этой областью.

Команда `#set-option "warn-tope-family-domain" = "no"` отключает предупреждение. Значение `"yes"` включает его. Команда `#unset-option "warn-tope-family-domain"` восстанавливает значение по умолчанию. Эти опции влияют только на предупреждение. Алгоритм по-прежнему пересекает семейство с его областью определения.

## Предупреждения о метапараметрах

Префикс метапараметров объявления заканчивается его последним схематическим параметром: универсумом, `CUBE`, `TOPE` или функцией, которая принимает такие параметры или возвращает такие значения. Алгоритм предупреждает, если объявление используется на объектном уровне до передачи всех параметров этого префикса.

Опция `warn-meta-prefix` принимает значения `"strict"` (по умолчанию), `"structural"` или `"off"`. Строгая проверка также предупреждает при передаче схемы с незаполненным префиксом локальной функции. Передача схемы схематическому параметру объявления верхнего уровня разрешена, если этот параметр находится в его префиксе метапараметров. Структурная проверка не накладывает дополнительного условия. Команда `#set-option "warn-meta-prefix" = "off"` отключает предупреждения, а `#unset-option "warn-meta-prefix"` восстанавливает значение по умолчанию.

Проверка охватывает определения, постулаты, предположения, `#check` и команды вычисления. Если классифицировать тип не удалось, алгоритм сообщает о незавершённой проверке. Эти диагностические сообщения не устанавливают уровни универсумов и не проверяют допустимость схематических подстановок.

## Предупреждения о фрагменте RSTT

Три дополнительные диагностические проверки сообщают об объявлениях вне фрагмента RSTT:

- `warn-free-standing-restriction` сообщает об ограничениях в предположениях вне непосредственного кодомена функции по форме. Это включает типы связанных переменных, мотивы элиминаторов, типы равенства и типы, передаваемые как данные. Ограничения вдоль кодоменов заключаемых типов разрешены.
- `warn-shape-dependency` сообщает об областях определения кубов, условиях форм и границах ограничений в предположениях, которые зависят от внешних кубических точек.
- `warn-meta-binder` сообщает о связывании схематических параметров внутри термов. Префикс параметров объявления и аргументы-схемы могут связывать такие параметры.

Каждая опция принимает значение `"yes"` или `"no"`. По умолчанию установлено `"no"`. Например, команда `#set-option "warn-shape-dependency" = "yes"` включает проверку зависимости форм. Команда `#unset-option "warn-shape-dependency"` восстанавливает значение по умолчанию. Настройки внутри секции не действуют за её пределами.

Проверки анализируют исходные выражения и типы после раскрытия определений. Если анализ не удаётся завершить, алгоритм сообщает о незавершённой проверке. Эти проверки не меняют допустимость объявлений, не устанавливают уровни универсумов и не проверяют допустимость схематических подстановок.
