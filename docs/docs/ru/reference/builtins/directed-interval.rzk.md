# Направленный интервал

Куб `#!rzk 2` — это направленный интервал, который является основой синтетической теории ∞-категорий.

```rzk
#lang rzk-1
```

## Точки направленного интервала

Направленный интервал `#!rzk 2` имеет две точки:

- `#!rzk 0_2` — начальная точка (источник)
- `#!rzk 1_2` — конечная точка (цель)

## Неравенство

Направленный интервал поддерживает топ неравенства `#!rzk <=` (или `#!rzk ≤`):

- `#!rzk t <= s` — это топ, который выполняется, когда `#!rzk t : 2` и `#!rzk s : 2` и `#!rzk t` меньше или равно `#!rzk s` в направленном порядке

Это неравенство используется для определени симплексов и для выражения направленности в синтетической теории ∞-категорий.

## Пример

```rzk
-- 2-симплекс использует неравенство, чтобы оставить только половину квадрата
#define Δ²
  : ( 2 × 2) → TOPE
  := \ (t , s) → s ≤ t
```

## Примечания

- Направленный интервал `#!rzk 2` отличается от единичного куба `#!rzk 1`
- Произведения кубов `#!rzk 2` (такие как `#!rzk 2 × 2`) используются для определения многомерных форм
- Неравенство `#!rzk ≤` валидно только для точек куба `#!rzk 2`
