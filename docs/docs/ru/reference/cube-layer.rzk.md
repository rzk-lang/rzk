# Слой кубов

```rzk
#lang rzk-1
```

Все кубы находятся во вселенной `#!rzk CUBE`.

Есть три встроенных куба:

1. Куб `#!rzk 1` — это единичный куб с единственной точкой `#!rzk *_1`
2. Куб `#!rzk 2` — это куб [направленного интервала](builtins/directed-interval.rzk.md) с точками `#!rzk 0_2` и `#!rzk 1_2`, с линейным порядком
3. Куб `#!rzk II` (или `#!rzk I`) — кубический интервал с точками `#!rzk 0_I` и `#!rzk 1_I`, без линейного порядка

`#!rzk 2` является подтипом `#!rzk II`: любая точка `#!rzk 2` может использоваться там, где ожидается `#!rzk II`. Кубический интервал `#!rzk II` используется аналогично `#!rzk 2`, но без тотального порядка:

```rzk
-- Кубический hom-тип в A между x и y
#define cub-hom
  (A : U) (x y : A)
  : U
  := (t : II) -> A [ t === 0_I |-> x , t === 1_I |-> y ]
```

Также возможно иметь переменные `#!rzk CUBE` и делать произведения кубов:

1. `#!rzk I * J` — это произведение кубов `#!rzk I` и `#!rzk J`
2. `#!rzk (t, s)` — это точка в `#!rzk I * J`, если `#!rzk t : I` и `#!rzk s : J`
3. если `#!rzk ts : I * J`, то `#!rzk first ts : I` и `#!rzk second ts : J`

Обычно вы можете использовать `#!rzk (t, s)` как в качестве паттерна, так и в качестве конструкции пары точек:

```rzk
-- Перестановка компонент точки в кубе I × I
#define swap
    ( I : CUBE)
  : ( I × I) → I × I
  := \ (t , s) → (s , t)
```
